# Apps

## Overview
Frontend client applications for Sentimeta delivering multi-platform web and mobile user interfaces across Next.js and Expo React Native.

## Subdirectories & Boundaries
- [web](./web/README.md) - Next.js 15 App Router web client with Clerk authentication, real-time feeds, chat, and emotion analytics.
- [native](./native/README.md) - Expo SDK 55 cross-platform mobile application for iOS and Android.
